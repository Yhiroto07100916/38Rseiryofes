# 在校判定・工具貸出通知の設定

在校状態は、工具貸出の貸出・返却通知の対象者を決めるために使用します。位置情報の利用は本人の明示的な操作で有効化し、GPS座標はサーバーへ送信した後に判定だけを行い、D1には保存しません。

## Cloudflare Worker の環境変数

Cloudflare Dashboard の Worker 38r-seiryofes → Settings → Variables and Secrets に以下を設定します。

| 変数 | 内容 |
|---|---|
| SCHOOL_LATITUDE | 学校敷地の代表点の緯度 |
| SCHOOL_LONGITUDE | 学校敷地の代表点の経度 |
| SCHOOL_GEOFENCE_RADIUS_METERS | 在校と判定する半径（30〜2,000m） |

座標はコードやGitに登録せず、Cloudflare側で設定してください。値が未設定の場合、GPS判定APIは503を返します。その場合、手動登録は利用できますが、GPSによる在校判定はできません。

## 在校状態の扱い

- GPS判定と手動登録を利用できます。
- GPSで校内と判定された場合、JSTの日付単位で出欠を自動的に「出席」として記録します。
- 同じ日のGPS再判定では、クラ代が手動変更した出欠状況を上書きしません。
- クラ代ページの出欠管理から、日付別名簿の確認・手動修正ができます。
- GPS判定はサイトを開いたとき・前面に戻ったときに実行されます。バックグラウンドで常時追跡するものではありません。
- GPSで校外と判定された場合、その日の手動在校登録はできません。
- 在校状態はJST 18:00または当日終了時に失効します。
- GPS取得に失敗しても、直前の有効状態を勝手に変更しません。
- アプリを閉じている間の継続的なGPS追跡は行いません。
- 本人はマイページから位置情報利用を停止できます。

## 工具貸出通知

- 貸出・返却時は、その時点で有効な在校状態のユーザーと操作した本人へ通知します。
- 返却期限10分前の通知は全ユーザーへ送信します。
- 既存の貸出タイマー終了通知は全ユーザーへ送信します。
- 返却期限超過通知は全ユーザーへ一度だけ送信します。
- 返却済みの貸出には期限通知を送信しません。
- 外部の工具貸出アプリとは連携しません。

期限10分前通知は固定値です。既存タイマーの終了通知とは別イベントとして管理します。

## Push配信とアプリ内通知

通知レコードはアプリ内通知として先に保存します。Push購読がないユーザーやPush配信に失敗した場合も、アプリ内通知は残ります。Push購読はユーザーIDに紐づきます。
