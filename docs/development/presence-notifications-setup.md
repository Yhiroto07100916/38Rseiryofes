# 在校判定・共通通知の環境設定

この機能は、学校の座標をコードへ直接書き込まず、Cloudflare Worker の環境変数で設定します。

## 必須設定

`worker/wrangler.jsonc` の `vars` に以下を追加するか、Cloudflare Dashboard の Worker Settings > Variables で設定してください。

| 変数 | 内容 |
|---|---|
| `SCHOOL_LATITUDE` | 学校の中心緯度 |
| `SCHOOL_LONGITUDE` | 学校の中心経度 |
| `SCHOOL_GEOFENCE_RADIUS_METERS` | 学校内と判定する半径（30〜2,000m） |

緯度・経度は学校敷地の代表点を使用してください。判定半径は敷地形状・GPS誤差を考慮して管理者が決定してください。値が未設定の場合、GPS判定APIは503を返し、在校状態を更新しません。

## 返却期限の接近通知

`TOOL_LOAN_DUE_SOON_MINUTES` は期限前通知の分数です。未設定時は10分を使用します。5〜1,440分の範囲で設定できます。

## データ・プライバシー

- 緯度・経度は判定リクエストでのみ利用し、D1には保存しません。
- D1には在校状態、判定方法、確認時刻、有効期限、JST日付のみ保存します。
- 位置情報利用の同意は本人がマイページで有効化・停止できます。
- GPS取得に失敗した場合、直前の有効状態を上書きしません。
- PWAを閉じている間の継続的な位置追跡は行いません。

## 通知

通知購読はログインユーザーIDに紐づきます。マイページでWeb Pushを登録し直すと、既存の端末購読も現在のアカウントへ紐づけられます。アプリ内履歴はPush購読の有無に関係なく保存されます。

工具貸出の故障・紛失管理項目は現行データモデルに存在しないため、このブランチでは通知対象に含めていません。
